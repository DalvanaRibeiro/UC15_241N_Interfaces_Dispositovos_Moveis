#  O que é React Native?

React Native é um **framework moderno** criado pela Meta (Facebook) para desenvolver aplicativos **nativos** usando:

- **JavaScript ou TypeScript**  
- **Componentes reutilizáveis**  
- **Estilo baseado em Flexbox**  
- **Hooks e conceitos do React**  




---

#  Por que usamos o Expo?

O **Expo** torna o desenvolvimento muito mais rápido:

- Sem instalar Android Studio no início  
- Rodamos o app pelo **Expo Go** no celular  
- Permite usar **câmera, GPS, sensores, imagens, vibração, haptics e muito mais**  
- Atualização instantânea  
- Configuração mínima  
- Deploy simples  

É a forma mais rápida de aprender e construir apps rapidamente.
