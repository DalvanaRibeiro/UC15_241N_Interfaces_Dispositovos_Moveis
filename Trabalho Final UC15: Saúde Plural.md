# 🎯 **Contexto da Atividade Final**

Nesta atividade, sua missão será desenvolver um aplicativo baseado no projeto interdisciplinar **Saúde Plural**, criado **em parceria com o Curso de Enfermagem**.

O objetivo do projeto é integrar tecnologia e saúde, permitindo que os estudantes criem **telas funcionais, modernas e úteis**, alinhadas ao protótipo oficial produzido pelo curso de Enfermagem no Figma.

Este trabalho representa não apenas a avaliação final da uc, mas também uma oportunidade de participar de uma proposta colaborativa entre áreas — unindo **Tecnologia + Saúde**.

# 🧭 **O que deve ser desenvolvido**

O aluno deverá construir as telas do projeto Saúde Plural utilizando:

### 1. **Componentes Nativos**
- View  
- Text  
- Image  
- ScrollView  
- TouchableOpacity  
- FlatList (quando necessário)

###  2. **Estilização**
- StyleSheet  
- Flexbox  
- Paleta e espaçamentos do Figma  
- Layout organizado e responsivo  

###  3. **Navegação com Expo Router **
- Estrutura baseada em pastas  
- Navegação via `router.push()` e `router.back()`

###  4. **Hooks**
- `useState`  
- `useEffect`  
- `useContext` (opcional, se desejar criar estados globais)

### ✔ 5. **Boas práticas**
- Código limpo  
- Componentização quando necessário  
- Organização clara de pastas
